## ⚙️ Loyihani ishga tushirish

### 1️⃣ Repository'ni yuklab olish

```bash
git clone https://github.com/maftuna571x/EDUHUB.git
cd EDUHUB
```

### 2️⃣ Virtual environment yaratish

```bash
python -m venv venv
```

### 3️⃣ Windows'da ishga tushirish

```bash
venv\Scripts\activate
```

### 4️⃣ Kerakli paketlarni o‘rnatish

```bash
pip install -r requirements.txt
```

### 5️⃣ Database migration

```bash
python manage.py migrate
```

### 6️⃣ Serverni ishga tushirish

```bash
python manage.py runserver
```
